# Noor Quran Academy — Website concept

A detailed responsive single-page website for an online Quran academy.

## Includes
- Premium emerald, ivory and gold design with Arabic-inspired decorative elements
- Academy introduction and six course cards: Noorani Qaida, Tajweed, Hifz, Translation & Understanding, Quran for Kids, Quran for Adults
- Learning process, teacher guidance, kids/adults sections and FAQ accordion
- Trial-class calls to action
- Contact form with age, course, schedule and message fields; prepares an email via mailto
- Mobile navigation, back-to-top button, accessible form labels and reduced-motion support

## Run
Open `index.html` in a browser. Google Fonts and the decorative Quran photo use external URLs and require internet.

## Update before launch
Replace `+92 300 1234567` and `info@example.com` in `index.html` and `app.js`. Confirm real fees, course details, teacher qualifications, schedule, trial terms and privacy policy. The form only opens the visitor's email app; it does not save submissions. Connect a secure form service/backend for reliable enquiries. This is a front-end concept, not a student portal or learning-management system.
