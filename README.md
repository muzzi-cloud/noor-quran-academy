# Noor Quran Academy — Responsive Website App

A polished, responsive front-end website for an online Quran academy, built with semantic HTML, CSS and vanilla JavaScript.

## Included
- Responsive sticky navigation with mobile menu
- Islamic-inspired emerald, cream and gold visual design
- Custom CSS hero illustration, Arabic typography and decorative geometry
- Six course cards with working category filters
- Four-step learning journey
- Teacher approach section
- Accessible FAQ accordion
- Enquiry form with required-field validation and a pre-filled email draft
- Quick-contact drawer, smooth scrolling, reveal animations and back-to-top link
- Reduced-motion support and visible keyboard focus styles

## Run locally
Open `index.html` in a modern browser. Google Fonts require an internet connection; fallback fonts are provided. No build step or package installation is required.

## Files
- `index.html` — semantic page structure and content
- `styles.css` — responsive visual system, components and animations
- `app.js` — menu, filters, FAQ, contact drawer, reveal animations and form behavior

## Accessibility notes
Includes semantic landmarks, form labels, keyboard focus states, ARIA-expanded state for interactive controls, live status messages, a skip link and reduced-motion support. Test with keyboard navigation and screen readers as part of launch QA.
